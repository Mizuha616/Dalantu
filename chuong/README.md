# Bản thảo chương

Khu vực lưu bản nháp, bản đã duyệt và lịch sử chỉnh sửa các chương **Dạ Lan Từ**.

## Quy ước
- Đặt tên: `Chuong_01.md`, `Chuong_02.md`...
- Đầu file ghi: **BẢN NHÁP / CHỜ DUYỆT / ĐÃ DUYỆT**.
- Không viết chương mới hoặc sửa nội dung chương đã duyệt nếu chưa được Linh Linh yêu cầu.
- Kiểm tra hồ sơ nhân vật, niên biểu và trục truyện trước khi triển khai.

Hiện **chưa có chương** được đưa vào repo này.
